# moexx399/homebrew-tap

Homebrew tap for [moexx399](https://github.com/moexx399) tools.

```bash
brew tap moexx399/tap
brew trust --cask moexx399/tap/vaultctx   # Homebrew 6+ requires trusting non-official taps
brew install --cask vaultctx
brew trust --cask moexx399/tap/vaultui    # Homebrew 6+ requires trusting non-official taps
brew install --cask vaultui
brew trust --cask moexx399/tap/ghstat     # Homebrew 6+ requires trusting non-official taps
brew install --cask ghstat
```

Casks in `Casks/` are generated by GoReleaser on release; do not edit them by hand.
